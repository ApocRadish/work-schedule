# Мой рабочий график — веб-приложение (PWA)

## Включено
- Устанавливаемое веб-приложение на главный экран Android при размещении на HTTPS-хостинге.
- Календарь месяца, обозначения Д/Н/О/выходной.
- Редактирование каждой даты, отпуск и ручное сохранение.
- Начальные данные октября 2026 по графику №154; отпуск 1–14 октября перекрывает смены.
- Экспорт смен и отпуска в `.ics`.
- Раздел «Зарплата»: прогноз начислений, НДФЛ, профсоюзных взносов, питания и ожидаемого остатка.
- Коэффициенты начислений по расчётным листкам за январь, февраль и сентябрь 2026 года, с ручной настройкой.
- Сохранение настроек зарплаты и графика на этом устройстве.
- Кеширование обновлённой оболочки для открытия без сети после первого посещения.

## Размещение
PWA и Service Worker требуют HTTPS (или localhost). Просто открыть `index.html` из папки недостаточно для установки и офлайн-режима. Самый простой способ — загрузить содержимое папки на статический HTTPS-хостинг, например GitHub Pages или Netlify Drop. После публикации открыть HTTPS-адрес в Chrome Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

## Ограничения уведомлений
Веб-приложение не гарантирует срабатывание будильника в 05:40, особенно при закрытом браузере или ограничениях батареи Android. Экспортируйте `.ics` в календарь для событий и напоминаний; для критичного подъёма поставьте системный будильник.

## Начальные смены
Дневные: 1, 4, 5, 8, 9, 11, 12, 13, 16, 17, 21, 22, 25, 26, 27, 30, 31 октября 2026. Ночная: 18 октября. Отпуск: 1–14 октября включительно. Источник — фото №154.


## Обновление уже опубликованного сайта
1. Распакуйте обновлённый ZIP.
2. В своём GitHub-репозитории замените файлами из папки `work-schedule-pwa` файлы `index.html`, `style.css`, `app.js`, `sw.js`, `manifest.json` и `README.md`.
3. Нажмите **Commit changes**. Через минуту перезапустите установленное приложение. Новая версия Service Worker очищает старый кеш; существующий график в localStorage сохраняется.

## Формула зарплаты
Подробная формула и проверка против трёх исходных расчётных листков приведены в `РАСЧЁТ_ЗАРПЛАТЫ.md`. Коэффициенты премий изменяются между месяцами, поэтому прогноз использует выбранный профиль. Часы смен, отпускные, питание и дополнительные удержания допускают ручную корректировку.
